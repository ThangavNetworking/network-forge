## Getting Started

### Prerequisites

You will need:

- Visual Studio Code
- Google Chrome or another modern browser
- Git (optional for local development)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/networkforge.git
   ```

2. Navigate to the project directory:

   ```bash
   cd networkforge
   ```

3. Open the project in Visual Studio Code:

   ```bash
   code .
   ```

4. Open `index.html` in your browser to view the website.

---

## Running the Website Locally

The website uses HTML, CSS, and JavaScript.

```text
index.html
```

in your browser.

## Deployment

This website can be deployed using GitHub Pages.

### Deployment Steps

1. Open the GitHub repository.
2. Navigate to Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select the `main` branch.
6. Select the `/ (root)` directory.
7. Click Save.

The website will be published at:

```text
https://YOUR_USERNAME.github.io/networkforge/
```

A custom domain can be connected later.
